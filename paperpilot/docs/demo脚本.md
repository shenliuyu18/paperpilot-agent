# PaperPilot · 产品演示脚本

> 成片时长 3 分 8 秒。所有操作都可以在离线模式下完成，不需要任何 API key。
> 录制脚本与旁白以 `../demo/demo_script.json`、`../demo/demo_timeline.json` 为准。

## 演示前检查

1. 启动：

   ```bash
   cd paperpilot
   python run.py
   ```

2. 浏览器打开 `http://127.0.0.1:8765`。
3. 确认左下角显示“离线规则模式”。
4. 确认左侧已自动检索“存算一体 低功耗 ADC”。
5. 研究库预置 4 篇论文、状态、标签与笔记（录制演示用）。
6. 关闭无关通知，浏览器缩放 100%。

---

## 0:00–0:19 开场

**旁白**：

> 大家好，这是 PaperPilot，一个从搜到论文，到读懂、比清、做出来的科研学习智能体。它支持 Crossref 与 arXiv 检索、跨论文证据问答、离线 PDF 图表和数值抽取，以及可以长期积累、可备份迁移的个人研究库。

## 0:19–0:31 检索

**操作**：检索“存算一体 SAR ADC 低功耗”，鼠标扫过结果卡片。

**旁白**：

> 先看检索。输入一个研究方向，可以在内置语料、arXiv 和 Crossref 之间切换；结果会标注来源、全文或摘要级，并给出头条指标。

## 0:31–0:47 精读

**操作**：点开 NeuDW-CIM，展示 TL;DR、问题/方法、指标、证据链。

**旁白**：

> 点开这篇神经形态 CIM 工作。右边是 TL;DR、问题与方法、关键指标、审稿人问题和证据链；新的离线解析还能提取图表标题、可核对数值和工艺验证方式。

## 0:47–0:55 翻译与证据

**操作**：点击“翻译”，展示双语对照弹窗。

**旁白**：

> 点击翻译，可以看到领域术语的双语对照；原文、译文和数值保持在一起，方便核对。

## 0:55–1:11 多篇对比

**操作**：勾选前 3 篇，进入“对比”。

**旁白**：

> 勾选三篇论文，进入对比。它自动抽取工艺、ADC 方案、任务和指标，并提醒：测试条件不同，数字不可直接排序。下面还会总结共识、分歧和可继续做的空白。

## 1:11–1:21 创新点

**操作**：进入“创新点”。

**旁白**：

> 创新点页把作者声称、实验证据和模型推断分开，避免把作者的话当成已验证事实，并给出审稿人问题。

## 1:21–1:29 论文到成果

**操作**：进入“成果”。

**旁白**：

> 成果页把论文变成可执行的东西：复现计划、最小验证实验、代码骨架、组会提纲和课程案例。

## 1:29–1:39 研究空白

**操作**：进入“研究空白”。

**旁白**：

> 研究空白雷达从证据缺口生成具体问题，附新颖性、可行性和影响评分，以及一个学期内能完成的最小实验。

## 1:39–1:55 证据问答

**操作**：

1. 进入“证据问答”；
2. 输入“五篇论文分别如何降低 ADC 开销？”；
3. 查看支持度矩阵、页码引用与可核对数值。

**旁白**：

> 再试一个跨论文问题：五篇论文分别如何降低 ADC 开销？PaperPilot 会先拆解问题、判断章节意图，再给出带页码的引用、每篇论文的支持度和可核对数值；没有命中的论文会明确标出。

## 1:55–2:10 我的研究库

**操作**：进入“我的库”，展示状态、标签、笔记与 Markdown/BibTeX/JSON 导出、导入按钮。

**旁白**：

> 读过的论文可以随时收藏。研究库里能按待读、在读、已读管理，打标签、写笔记，还能导出 Markdown、BibTeX 或 JSON 备份；JSON 备份可以在另一个实例恢复。

## 2:10–2:26 批量 PDF 解析

**操作**：

1. 点击“上传 PDF”，选择两篇示例 PDF；
2. 等待解析完成，展示左侧两篇上传论文；
3. 展示关键指标、图表数与“可核对数值”。

**旁白**：

> 上传 PDF 也升级了。一次可以选择多篇，PaperPilot 会离线提取作者、工艺、图表、结果数值和局限，并自动打开最近解析的一篇；两篇论文都进入左侧结果，随时可以一起对比。

## 2:26–2:43 选题与写作

**操作**：

1. 进入“选题”，生成选题地图，滚动到候选问题与阅读路径；
2. 进入“写作”，生成相关工作草稿，填入示例并开始主张核查。

**旁白**：

> 再看研究流程。选题页把方法簇和证据缺口变成候选问题、阅读路径和最小实验；写作页生成带引用键的相关工作草稿，再用主张核查逐句找出没有证据、或数值对不上的地方。

## 2:43–3:08 评测与收尾

**操作**：进入“评测”，展示 41 条用例与 41/41 结果。

**旁白**：

> 最后是评测：四十一条回归用例，覆盖检索与 Crossref、离线 PDF 抽取、选题、写作与逐句核查、对比、转化、研究空白、证据问答和研究库备份，当前四十一条全部通过。PaperPilot 的目标不是替代阅读，而是让每一次阅读都留下可核查、可复用、可执行的资产。

## 演示故障预案

| 故障 | 处理 |
|---|---|
| 浏览器打不开 | 确认 `python run.py` 仍在运行；访问 `http://127.0.0.1:8765/api/health` |
| 端口被占用 | `python run.py --port 8877` |
| arXiv / Crossref 在线检索失败 | 切回“内置演示语料”；所有离线功能不依赖网络 |
| 批量上传失败 | 检查 PDF 是否 ≤25 MB、≤80 页；单次最多 5 篇 |
| 研究库为空 | 先收藏几篇论文，或重新运行演示数据准备步骤 |
| 页面缓存旧版本 | `Ctrl+F5`；确认静态资源查询参数为 `v=3.1.0` |
| 演示网络完全不可用 | 直接播放提前录好的 3 分 8 秒演示视频 |
